About this utility

Encrypted offsite backups for FollowUp Desk staging

FollowUp Desk Backups is a privately operated utility that copies verified backups of the FollowUp Desk fictional-data staging environment to an operator-controlled Google Drive account.

What the utility does

When scheduled by the operator, GitHub Actions exports a staging PostgreSQL database and private test-file storage, verifies the backup, encrypts its contents and names using rclone crypt, then sends it to Google Drive. A separate isolated restore test can be used to confirm that an offsite backup is recoverable.

The utility is not a public sign-in service, is not for customer use, and is separate from the FollowUp Desk application.

Why Google Drive permission is requested

The operator authorizes Google Drive access so rclone can upload, list, verify, and retrieve encrypted backup files. Google may grant an access scope broader than the specific backup directory. The backup utility is configured to work within its designated encrypted backup location; it is not intended to inspect unrelated Drive content.

Security and data handling

Backup database and test-file contents are processed temporarily during backup execution, encrypted before being stored in Google Drive, and are not published to this website or a GitHub repository. Google Drive may retain ordinary file metadata such as sizes and modification times. See the Privacy Policy for details.

Current use is limited to fictional staging records. This page is not the privacy notice or terms for end users of the separate FollowUp Desk software.
