# FollowUp Desk Backups — public information site

This repository contains **only public informational pages** for the privately operated
FollowUp Desk Backups Google OAuth utility. It has no login or runtime backup functionality.

- [Homepage](https://alexanderestrela784-glitch.github.io/)
- [Privacy policy](https://alexanderestrela784-glitch.github.io/privacy.html)
- [Terms of use](https://alexanderestrela784-glitch.github.io/terms.html)

The actual automated backup code, encrypted files, database exports, Google Drive
authorization secrets, and credentials remain outside this repository in a
**separate private repository or encrypted storage**.

## Publishing the static site

Repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Google might require further Google Search Console ownership/domain verification
before accepting the site for an external OAuth consent screen. Public hosting
alone does not guarantee OAuth publication or verification.
