Privacy Policy

This policy covers only the privately operated FollowUp Desk Backups Google OAuth utility, not the separate FollowUp Desk SaaS product. At present, this utility is used for backup of fictional staging data.

Data and access

With the operator's consent, the utility uses Google's Drive API through rclone to upload, list, check, and retrieve encrypted backup files and associated Drive metadata (for example filenames as stored, sizes, timestamps, and file identifiers). Depending on the OAuth scope granted, Google authorization may technically permit access to other files in the account; the configured backup workflow is intended to work only in its designated encrypted backup directory.

How data is used

Google Drive access is used solely for operating and checking backup and recovery. The utility does not use Google Drive data for advertising, user profiling, model training, or sale of data. It does not share Google Drive data with advertisers or data brokers.

Storage, subprocessors, and security

Backup contents and filenames are encrypted with rclone crypt before upload to the operator's Google Drive account. Database exports and private test files temporarily exist in memory-backed storage during a hosted GitHub Actions run, and that temporary staging folder is removed when the job ends. Credentials used by the job are stored as private GitHub Actions secrets, not in public repository files. Google and GitHub process technical information necessary to provide their respective services. The operator may download and decrypt a backup for an isolated recovery check.

Retention and deletion

Encrypted backup files remain in the operator's Google Drive account until the operator deletes them. The current backup workflow is append-only and does not automatically delete old copies. The operator can delete the files from Drive and revoke Drive authorization in their Google Account settings. Revoking access stops future authorized access but does not automatically remove previously uploaded files. Provider-level backup and deletion behavior may be governed by Google and GitHub policies.

Public website data

This informational website has no login, form, analytics integration, or third-party advertising scripts. The static site host may process ordinary request and security logs under its own policies.

Contact and updates

For questions about this private utility or Google authorization, contact the operator using the support email displayed on the FollowUp Desk Backups Google OAuth consent screen. This policy will be updated if the utility's purposes or data practices materially change.
